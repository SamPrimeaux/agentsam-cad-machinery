# AgentSam CAD Machinery

**Engineering the imagined into the buildable.**

The canonical workspace for the specialized CAD, BIM, geometry, visualization and spatial-production machinery used by AgentSam. The purpose is to graduate existing, tested capabilities into reliable production workflows—not reproduce the SDK, spin up another CAD editor, or create a second project authority.

The public product is **CAD Creator**. The execution architecture is **SAM (Systematic Autonomous Machinery)**. Portable `cad.project` contracts, `sam.invoke()`, hooks, capability routing and installation conventions remain under `agentsam-sdk`.

## Connected work

- **[Case Studies](case-studies/dream-house/README.md)** — real work, source-backed narratives and deliverables. DreamHouse is the first integrated architectural production case study.
- **[CAD source ownership](docs/OWNERSHIP.md)** — where existing code lives, how it graduates here, and the verification requirements before moving or deprecating any implementation.
- **[BIM library index](catalog/bim-starters.index.json)** — source references and checksums for two existing FreeCAD/GLB asset sets uploaded to the `cad` R2 bucket. This is lightweight metadata, not duplicated model files.

## Production intent

**Intent and references → verified dimensional CAD → semantic BIM and drawings → Blender / optimized interactive scene → MovieMode/CoPro cinematic presentation → contractor/architect review package.**

All generated artifacts must trace to the same project revision. Native tool discovery is not proof of completed output; successful operations need real produced files, validation and receipts. High-fidelity presentation is a baseline deliverable, not a substitute for accurate geometry.

## Current repository state

This is the *initial source and case-study governance foundation*. The working implementations currently remain in their established SDK, CAD service, 3D Studio and MovieMode locations. No code or large binary assets have been migrated, and no case-study render or professional construction document is claimed complete here.

The next engineering step is an ownership/provenance audit followed by cohesive, tested implementation graduation. Any remaining structural, code-compliance or professional-seal decisions remain explicitly pending appropriately licensed reviewers.

**Craft over spectacle. Substance over promises.**
