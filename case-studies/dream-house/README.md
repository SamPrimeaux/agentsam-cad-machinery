# DreamHouse — Architecture from intent to inhabitable world

**Stage:** In production. This is a case study, not a stock demonstration or generic architectural template.

## Creative and engineering brief

Carry the approved DreamHouse intent through one canonical, revisioned architectural project. Establish the design in dimensioned 2D, coordinate a semantic BIM model, generate professional-review drawings and schedules, produce synchronized exterior/interior scenes, and present the built environment as an interactive walkthrough and edited cinematic story.

The SD-02-RC1 project and reference images already exist outside this repository. Their original sources and revision locks remain authoritative until explicitly adopted through the portable project contract and migration checks. No existing DreamHouse document or design lock is moved or overwritten by this repository initialization.

## Presentation deliverables

| Presentation | Production requirement |
| --- | --- |
| Design direction | Approved reference imagery, concept alternatives, design rationale |
| Architectural drawings | Site, floor, roof, elevation, sections and schedules; real dimensioned vector/PDF outputs |
| Building information | Editable source geometry, IFC/BIM semantics, component and assembly identifiers |
| Aerial and exterior imagery | High-fidelity stills derived from the approved geometry; separate references from renders |
| Interactive world | Optimized GLB, materials, lighting, navigation and scene-state changes |
| Cinematic work | Camera paths, source shots, editable MovieMode/CoPro project and verified encoded video |
| Professional handoff | Coordinated package of sources, documents, quantities, issues, revision records and receipts |

The story should show the work progressing—from initial intent and craft decisions to geometry, technical detail, and its interactive world—without representing incomplete engineering as certified construction documents.

## Delivery standards

Every public image, shot, drawing and file should reference its generating project revision and actual source asset. Publishing requires deliberate permission and QA review. A CD-preparation package is **for licensed professional review**, not itself a sealed permit set.

**Current repository scope:** Case-study production specification and provenance pointers. No new house model, BIM export, drawing PDF or video is claimed as built by this initialization.
